Blend: `_web/Scene_WEB.blend` (WORK file `_work/Scene_WORK_farm.blend` is untouched). Web project: `Vorta_Warehouse/web` (Vite 5.4.10, three 0.170.0, gsap 3.12.5).

## Architecture (agreed)
- Two clocks. Scroll drives Blender's frame (1-1044 @24 fps): camera pan/zoom (ortho iso camera, shift + ortho_scale), truck pose + wheels, sky/sun colors (day->night 240-740), trail reveal, build-in pops (1,201 objects, 2 curve variants, 29 frames), window light-ons.
- Real time drives every ambient loop regardless of scroll. Loops appear once their part of the world is built (gates).
- Lighting: static world merged into zone meshes BK_W/M/R/C1/C2/C3 + terrain tiles BK_T0-T3, baked in layers (sky, sun = full colour under white light; lamps = real colours; trail = grayscale) and mixed in a custom shader with timeline colours. Moving objects lit live (hemi + directional).
- Sun fixed at 49.5 deg / -166.3 deg (rotation keys removed; colour/energy keys kept for the timeline).
- Every object has custom prop `web_role`: static, story_buildin, static_sway, ambient, traffic, truck, trail, bake_light, trail_light, story_light, exclude, bake_zone.

## Scripts (`_web/scripts`, also as text blocks in the blend)
- `web_build_bake_meshes.py`: merges zones, lightmap UVs (smart project), vertex attrs pivot/ent/lighton/sway/objid. Unhide WEB_Bake layer collection before running (edit-mode ops need it).
- `web_bake.py`: background bake, resumable, per layer. Run: `Blender -b Scene_WEB.blend -P scripts/web_bake.py -- --samples 128 [--zones W,T0] [--layers sky,sun]`. Writes `_web/bake/<zone>_<layer>.exr`. Full bake ~15 min.
- `web_export.py`: steps lightmaps, zones, timeline, lights, glbs -> `web/public/assets` (manifest.json, zones/*.bin, lightmaps/*.webp, ambient/truck/props/traffic.glb). Run in background: `-- glbs` etc.
- Always run heavy jobs as background processes (MCP calls time out at 4 min and freeze the GUI).

## Gotchas learned
- glTF exporter evaluates static transforms at scene frame_start: build-in objects export squashed/hidden. Fix (patch pending in web_export.py): set frame_start=frame_end=1044 during GLB export; also mute animated hide_* curves (class Unhidden, done).
- Coplanar/overlapping geometry bakes black (terrain tile overlap fixed; road markings need a 2-3 cm lift).
- Terrain tiles: each face in exactly one tile; UV rect must cover the tile's real vertex bounds (inner edges currently lack margin -> trail glow seam at y=307). FIX PENDING.
- Faces without material get no bake target (WH_Shell fixed with WEB_Default).
- Glass has no diffuse -> needs a transparent pass in the web.
- Lightmap mipmaps disabled as a stopgap -> causes grain at distance. Proper fix: dilate EXRs (fill empty atlas space) then re-enable mipmaps.
